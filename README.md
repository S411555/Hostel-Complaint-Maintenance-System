# Hostel Complaint & Maintenance System

## Description
A simple database project that manages hostel complaints and maintenance staff assignments.

## Features
- Student complaint registration
- Assign staff to issues
- Track complaint status (Pending / Fixed)
- Join queries for reporting

## Tables
- students
- staff
- complaints

## Tools Used
- MySQL

## How to Run
1. Open MySQL Workbench / XAMPP
2. Run SQL script
3. Execute queries step by step
